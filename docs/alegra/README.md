# Estudio de Alegra (inspiración, no copia)

Aquí va el mapa de cómo Waldy usa Alegra hoy, sacado de recorrer una **cuenta de prueba** (nunca la cuenta real de Medoxigas).

Reglas:
- Describir flujos, campos y reglas de negocio con nuestras palabras. No copiar código, textos largos, logos ni el diseño exacto.
- Las capturas van en `docs/alegra/capturas/` solo si no muestran datos reales de clientes; si los muestran, no se suben.
- Nunca guardar aquí correos, contraseñas ni tokens de Alegra.

Un archivo por área:
- `facturacion.md` — facturas de venta, comprobantes fiscales (NCF / e-CF), notas de crédito.
- `clientes-productos.md` — contactos, ítems, precios, impuestos (ITBIS).
- `cxc.md` — cuentas por cobrar, pagos recibidos, estados de cuenta.
- `gastos.md` — compras, gastos, proveedores (606).
- `bancos.md` — cuentas, conciliación.
- `reportes.md` — reportes contables y fiscales (606, 607, IT-1).

Cada archivo: pantallas, campos obligatorios, cálculos, estados del documento, qué hace Waldy de verdad y qué no usa.
